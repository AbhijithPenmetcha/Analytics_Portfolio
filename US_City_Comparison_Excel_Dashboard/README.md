# US City Comparison & Livability Dashboard

**Advanced Excel | VBA & Macros | PivotTables | Interactive Dashboards | Comparative Analytics**

## Project Overview

Choosing where to live involves more than comparing salaries or rental prices. Weather, affordability, diversity, taxes and lifestyle preferences can all influence the decision.

This project brings these factors into an interactive Excel dashboard designed to compare US locations across multiple quality-of-life indicators.

Built as a collaborative project, the workbook combines comparative data analysis with advanced Excel reporting tools and VBA-enabled dashboard controls.

## Business Problem & Objectives

- Consolidate multiple location-based indicators into a structured comparison.
- Evaluate differences in affordability, diversity, weather and lifestyle characteristics.
- Compare locations across several criteria rather than relying on a single ranking.
- Build an interactive dashboard that makes the analysis easier to explore.

## Excel Skills & Technical Implementation

### 1. PivotTables & Data Analysis

- Created 10 PivotTables to summarize metrics across locations.
- Analyzed average rent, average income, tax rates and diversity rankings.
- Organized weather and lifestyle indicators into comparable views.
- Developed an overall ranking view using category-level scores.

### 2. Interactive Dashboard Development

- Created a dashboard supported by 11 Excel charts.
- Incorporated slicers for interactive filtering.
- Connected dashboard elements to underlying analytical tables.
- Organized the analysis into summary views and category-specific worksheets.

### 3. VBA & Macros

- Incorporated an embedded VBA project into the macro-enabled Excel workbook.
- Integrated macro-linked dashboard buttons including a slicer-reset control and an additional custom VBA action.
- Combined Excel's built-in interactive functionality with macro-enabled controls.

### 4. Comparative Analysis & Reporting

The workbook examines:

- **Affordability:** Average income, rent and income-to-rent comparisons
- **Diversity:** Socioeconomic, cultural, economic, household, religious and political diversity indicators
- **Weather:** Temperature, precipitation and humidity
- **Lifestyle:** Entertainment and nightlife
- **Taxes:** Comparative tax rates
- **Overall Ranking:** Consolidated location scores
